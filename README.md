
# Mi Calculadora de Ahorro Personal

Bienvenido a la Calculadora de Ahorro Personal. Esta aplicación te ayuda a tomar el control de tus finanzas gestionando ingresos, gastos y estableciendo metas de ahorro.

## Información del Proyecto

Este proyecto es una aplicación web moderna construida para ayudarte a visualizar y planificar tu salud financiera.

## Tecnologías Utilizadas

Este proyecto utiliza las siguientes tecnologías:

- [Vite](https://vitejs.dev/) - Entorno de desarrollo frontend de próxima generación.
- [TypeScript](https://www.typescriptlang.org/) - JavaScript con tipado estático.
- [React](https://react.dev/) - Biblioteca para interfaces de usuario web y nativas.
- [shadcn/ui](https://ui.shadcn.com/) - Componentes de interfaz bellamente diseñados.
- [Tailwind CSS](https://tailwindcss.com/) - Framework CSS de utilidad primero.

## Cómo Ejecutar Localmente

Sigue estos pasos para ejecutar el proyecto en tu máquina local:

### Requisitos Previos

Asegúrate de tener instalados [Node.js](https://nodejs.org/) y npm.

### Instalación

1.  Clona el repositorio:
    ```bash
    git clone <TU_URL_DEL_REPOSITORIO>
    ```

2.  Navega al directorio del proyecto:
    ```bash
    cd calculahorro
    ```

3.  Instala las dependencias:
    ```bash
    npm install
    ```

4.  Inicia el servidor de desarrollo:
    ```bash
    npm run dev
    ```

5.  Abre tu navegador en `http://localhost:8080` (o el puerto que indique la consola).
